# Playbox Arcade
A React + Vite gaming portal prototype with a responsive game-library homepage, category filters, search, local favorites, the existing Playbox Match game, Tic-Tac-Toe, and Reaction Rush. Neon Snake and other listed tiles are currently clearly marked as previews/coming soon.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Notes
- Favorites are saved in browser LocalStorage.
- Playbox Match files from the supplied project are kept under `public/playbox/` and launched as a local iframe.
- External games should only be embedded or redistributed when their license/owner permits it.
- This is a frontend prototype; no accounts, online leaderboard, or ad integration are configured.
